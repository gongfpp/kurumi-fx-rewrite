# FX 提示音

这组音效为**动画交易终端风格参考重制**，由 `tools/build-fx-sfx.py` 原创合成，没有从动画剪辑音效，也没有使用 Kenney 卡牌、筹码或骰子素材。保留在 `voice/` 的人物对白才是官方 PV 原声。

参考来源为 [KADOKAWAanime 官方主 PV](https://www.youtube.com/watch?v=7rxIZ3z0S4s) 的交易终端画面、盈利与风险通知场景及提示节奏。已有官方混音包含对白与音乐，没有独立音效轨；不能将混音裁片宣称为干净、完整的原版音效。本组的音高、音色由生成脚本原创设计，不声称复刻原轨。

| 文件 | 用途 |
| --- | --- |
| terminal-tap.mp3 | 按钮确认，替代切牌声 |
| profit-notice.mp3 | 盈利提示 |
| risk-notice.mp3 | 亏损、风险提示 |
| news-notice.mp3 | 市场快讯 |
| success-notice.mp3 | 成就、结算盈利 |
| order-confirm.mp3 | 下单、护盘确认 |
| order-close.mp3 | 平仓、消费物品 |
| quote-tick.mp3 | 仅供显式试听，实时行情默认不播放 |

所有短音都有 40–140 毫秒静默前摇及平滑起落，每个音符使用正弦平方包络；编码后的峰值不超过 −16 dBFS，页面默认音量再乘 0.5。播放速度限制为 0.8–1.25 倍，短时频控与最多两个叠音避免连续操作堆积。静音、切入后台、离开页面立即暂停，无需加载所有音频。

`SOURCES.json` 保留时长、解码响度、哈希与来源边界。已完成解码和数字峰值校验，未声称人工实听验收。
